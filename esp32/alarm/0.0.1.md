# Перший прототип

## Мета

Створити перший прототип домашньої системи сигналізації на базі ESP32.

Система повинна визначати рух за допомогою PIR-сенсора та показувати
поточний стан за допомогою світлодіодів.

## Обладнання

- ESP32
- PIR-датчик руху
- зелений світлодіод
- червоний світлодіод
- резистори для світлодіодів
- з'єднувальні проводи

## Поведінка системи

Система має два стани:

### Нормальний стан

Якщо рух не виявлено:

- зелений світлодіод світиться;
- червоний світлодіод не світиться.

### Виявлено рух

Якщо PIR-сенсор зафіксував рух:

- зелений світлодіод вимикається;
- червоний світлодіод вмикається.

Після того як сенсор перестає фіксувати рух, система повинна повернутися
до нормального стану.

## Схема роботи

PIR sensor
    ↓
ESP32
    ↓
визначення стану
    ↓
┌─────────────┬─────────────┐
│ руху немає  │ рух є       │
│ GREEN ON    │ GREEN OFF   │
│ RED OFF     │ RED ON      │
└─────────────┴─────────────┘

## Завдання

1. Ознайомтесь із принципом роботи PIR-сенсора.
2. Визначте, які GPIO ESP32 будете використовувати для:
   - PIR-сенсора;
   - зеленого LED;
   - червоного LED.
3. Намалюйте або опишіть схему підключення.
4. Підключіть компоненти до ESP32.
5. Реалізуйте необхідну логіку програми.
6. Завантажте програму на ESP32 та перевірте її роботу.

## Вимоги

Програма повинна:

- отримувати стан PIR-сенсора;
- правильно визначати наявність руху;
- керувати двома світлодіодами;
- не допускати одночасного світіння зеленого та червоного LED;
- виводити в Serial Monitor поточний стан системи:
  - `NO MOTION`
  - `MOTION DETECTED`

## Перевірка

Продемонструйте викладачу:

1. Стан системи без руху.
2. Реакцію системи на рух.
3. Повернення системи до нормального стану.
4. Повідомлення у Serial Monitor.

## Пояснення

Будьте готові пояснити:

- як PIR-сенсор повідомляє ESP32 про рух;
- що таке GPIO;
- які піни працюють як INPUT, а які як OUTPUT;
- навіщо світлодіоду потрібен резистор;
- як програма приймає рішення, який LED увімкнути;
- що станеться, якщо змінити GPIO одного з компонентів у схемі,
  але не змінити його в програмі.

## ⭐ Додаткове завдання

Додайте третій стан:

`ALARM`

Якщо рух фіксується протягом певного часу, система повинна перейти
в стан тривоги.

Самостійно визначте:

- через скільки часу це має відбутися;
- як система повинна показувати стан `ALARM`;
- як система повинна повернутися до нормального стану.
