# Практична робота: кошик інтернет-магазину

## Мета роботи

Закріпити використання:

- об’єктів і масивів;
- деструктуризації об’єктів;
- spread-синтаксису;
- rest-параметрів;
- конструкції `try...catch`;
- функцій;
- отримання значень із HTML-елементів;
- виведення результату на вебсторінку.

## Завдання

Створіть вебсторінку інтернет-магазину, на якій користувач може додавати товари до кошика та бачити загальну вартість замовлення.

Користувач повинен мати можливість:

1. Обрати товар.
2. Вказати кількість одиниць товару.
3. Натиснути кнопку **«Додати до кошика»**.
4. Побачити перелік доданих товарів.
5. Побачити загальну вартість кошика.
6. Отримати зрозуміле повідомлення, якщо введені дані неправильні.

## Товари

| Товар | Вартість |
|---|---:|
| Комп’ютерна миша | 500 грн |
| Клавіатура | 800 грн |
| Навушники | 1200 грн |
| USB-накопичувач | 300 грн |

Початкові дані можна подати у вигляді масиву об’єктів:

```js
const products = [
  { id: 1, name: "Комп’ютерна миша", price: 500 },
  { id: 2, name: "Клавіатура", price: 800 },
  { id: 3, name: "Навушники", price: 1200 },
  { id: 4, name: "USB-накопичувач", price: 300 }
];
```

Кошик на початку роботи програми повинен бути порожнім:

```js
let cart = [];
```

## Обов’язкові вимоги

1. Інтерфейс повинен містити:
   - список для вибору товару;
   - поле для введення кількості;
   - кнопку **«Додати до кошика»**;
   - блок із переліком товарів у кошику;
   - блок із загальною вартістю;
   - блок для повідомлень про помилки.

2. Кожен товар у масиві `products` повинен бути об’єктом із властивостями:
   - `id`;
   - `name`;
   - `price`.

3. Під час роботи з товаром потрібно використати **деструктуризацію об’єкта**:

```js
const { name, price } = product;
```

4. Під час додавання товару потрібно створити об’єкт елемента кошика, не змінюючи початковий об’єкт товару:

```js
const cartItem = {
  ...product,
  quantity: quantity
};
```

5. Новий елемент потрібно додавати до нового масиву за допомогою **spread-синтаксису**:

```js
cart = [...cart, cartItem];
```

6. Загальну вартість потрібно розраховувати у функції `calculateTotal()`, яка використовує **rest-параметри**:

```js
function calculateTotal(...prices) {
  // Розрахунок загальної суми
}
```

Перед викликом функції потрібно отримати масив вартостей позицій кошика:

```js
const itemTotals = cart.map(/* обчислення вартості кожної позиції */);
const total = calculateTotal(...itemTotals);
```

7. Додавання товару потрібно виконувати у функції `addToCart()`.

8. У функції `addToCart()` потрібно використати `try...catch`.

9. Програма повинна створювати помилку за допомогою `throw new Error()`, якщо:
   - товар не вибрано;
   - кількість не є числом;
   - кількість менша за 1.

Приклад:

```js
if (quantity < 1) {
  throw new Error("Кількість повинна бути не меншою за 1");
}
```

10. Блок `catch` повинен перехоплювати помилку та показувати її повідомлення на сторінці:

```js
catch (error) {
  // Вивести error.message на сторінку
}
```

11. Для кожної позиції кошика потрібно показувати:
   - назву товару;
   - ціну однієї одиниці;
   - кількість;
   - вартість позиції.

12. Після успішного додавання товару потрібно оновити перелік товарів і загальну вартість.

## Приклад роботи програми

Користувач додав:

- клавіатуру — 2 одиниці по 800 грн;
- комп’ютерну мишу — 1 одиницю за 500 грн.

Розрахунок:

```text
Клавіатура: 800 × 2 = 1600 грн
Комп’ютерна миша: 500 × 1 = 500 грн

1600 + 500 = 2100 грн
```

Очікуваний результат:

```text
Клавіатура — 2 шт. — 1600 грн
Комп’ютерна миша — 1 шт. — 500 грн

Загальна вартість: 2100 грн
```

Приклад повідомлення про помилку:

```text
Помилка: кількість повинна бути не меншою за 1
```

## Додаткове завдання

Для отримання вищої оцінки реалізуйте одну або декілька можливостей:

- додайте кнопку **«Очистити кошик»**;
- додайте кнопку видалення окремого товару;
- показуйте загальну кількість товарів у кошику;
- якщо товар уже є в кошику, збільшуйте його кількість замість додавання нової позиції;
- додайте промокод `STUDENT`, який надає знижку 10%;
- зберігайте кошик у `localStorage`;
- зробіть сторінку зручною для перегляду на телефоні.

## Захист роботи

Під час захисту потрібно:

1. Показати додавання кількох товарів до кошика.
2. Продемонструвати обробку неправильного значення кількості.
3. Пояснити різницю між destructuring, spread і rest.
4. Пояснити роботу функцій `addToCart()` і `calculateTotal()`.
5. Передбачити результат для одного контрольного набору даних.
6. Виконати невелику зміну в коді за завданням викладача.

Приклади змін під час захисту:

- змінити ціну одного товару;
- додати новий товар;
- змінити текст повідомлення про помилку;
- додати перевірку максимальної кількості товару;
- вивести ще одну властивість товару;
- знайти й виправити просту помилку в коді.

Можна використовувати AI, документацію та приклади, але студент повинен розуміти зданий код, уміти пояснити його та внести просту зміну.
