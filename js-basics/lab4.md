# Практична робота: калькулятор вартості автомийки

## Мета роботи

Закріпити використання:

- змінних;
- чисел, рядків і логічних значень;
- умовних операторів `if`, `else if`, `else`;
- базових функцій;
- отримання значень із HTML-елементів;
- виведення результату на вебсторінку.

## Завдання

Створіть вебсторінку, яка розраховує вартість миття автомобіля.

Користувач повинен мати можливість:

1. Обрати тип автомобіля.
2. Обрати додаткові послуги.
3. За бажанням ввести промокод.
4. Натиснути кнопку **«Розрахувати»**.
5. Побачити остаточну вартість замовлення.

## Вартість послуг

| Послуга | Вартість |
|---|---:|
| Миття легкового автомобіля | 300 грн |
| Миття кросовера | 400 грн |
| Миття мікроавтобуса | 500 грн |
| Миття салону | +250 грн |
| Нанесення воску | +100 грн |
| Чорніння шин | +80 грн |

Промокод `STUDENT` надає знижку **10%** на всю суму замовлення.

## Обов’язкові вимоги

1. Інтерфейс повинен містити:
   - список для вибору типу автомобіля;
   - прапорці для вибору додаткових послуг;
   - поле для введення промокоду;
   - кнопку **«Розрахувати»**;
   - блок для виведення результату.
2. Розрахунок потрібно виконувати у функції `calculatePrice()`.
3. Базову вартість потрібно визначати за допомогою `if`, `else if` та `else`.
4. Для кожної вибраної додаткової послуги відповідна сума повинна додаватися до загальної вартості.
5. Якщо введено промокод `STUDENT`, від загальної вартості потрібно відняти 10%.
6. Якщо тип автомобіля не вибрано, потрібно показати зрозуміле повідомлення про помилку.
7. Результат потрібно вивести на сторінку, наприклад:

   > Загальна вартість: 675 грн

## Приклад роботи програми

Користувач обрав:

- кросовер — 400 грн;
- миття салону — 250 грн;
- нанесення воску — 100 грн;
- промокод `STUDENT` — знижка 10%.

Розрахунок:

```text
400 + 250 + 100 = 750 грн
750 - 10% = 675 грн
```

Очікуваний результат:

```text
Загальна вартість: 675 грн
```

## Додаткове завдання

Для отримання вищої оцінки реалізуйте одну або декілька можливостей:

- показуйте перелік вибраних послуг;
- додайте кнопку **«Очистити»**;
- додайте послугу **«Миття двигуна» — 200 грн**;
- показуйте повідомлення **«Велике замовлення»**, якщо сума перевищує 700 грн;
- змінюйте колір блоку з результатом залежно від вартості;
- зробіть сторінку зручною для перегляду на телефоні.

## Захист роботи

Під час захисту потрібно:

1. Показати роботу калькулятора.
2. Пояснити призначення основних змінних, умов і функції `calculatePrice()`.
3. Передбачити результат для одного контрольного набору даних.
4. Виконати невелику зміну в коді за завданням викладача.

Приклади змін під час захисту:

- змінити вартість однієї послуги;
- змінити промокод або розмір знижки;
- додати ще одну послугу;
- додати нову умову;
- знайти й виправити просту помилку в коді.

Можна використовувати AI, документацію та приклади, але студент повинен розуміти зданий код, уміти пояснити його та внести просту зміну.
