# React Router: два альтернативні формати практичної роботи

**Для кого:** студенти 3 курсу професії «Оператор з обробки інформації та програмного забезпечення», 16–18 років.  
**Основа:** попередній застосунок із трьома курсами та компонентом `CourseCard`.  
**Час:** 45–60 хвилин на один обраний формат.  
**Оцінювання:** 4 + 4 + 4 = 12 балів.

Виконайте один формат за вибором викладача. Перед початком запустіть свій попередній проєкт. Для обох форматів потрібні React Router і `BrowserRouter`, який огортає `App` один раз.

## Початковий фрагмент для формату 1

У `main.jsx` застосунок уже має бути огорнутий у `BrowserRouter`. Наведений фрагмент замінює `App.jsx` для цієї вправи. У ньому навмисно є проблеми.

```jsx
import { Link, Route, Routes, useParams } from "react-router";

const courses = [
  { id: 1, title: "Основи HTML", teacher: "Олена Коваль" },
  { id: 2, title: "Основи React", teacher: "Роман Бондар" },
  { id: 3, title: "Робота з Git", teacher: "Ірина Савчук" }
];

function CourseList() {
  return (
    <main>
      <h1>Навчальні курси</h1>
      {courses.map(function (course) {
        return (
          <article key={course.id}>
            <h2>{course.title}</h2>
            <Link to="/courses/1">Детальніше</Link>
          </article>
        );
      })}
    </main>
  );
}

function CourseDetails() {
  const { id } = useParams();
  const course = courses.find(function (item) {
    return item.id === id;
  });

  return (
    <main>
      <h1>{course.title}</h1>
      <p>{course.teacher}</p>
      <Link to="/catalog">До списку курсів</Link>
    </main>
  );
}

export default function App() {
  return (
    <Routes>
      <Route path="/" element={<CourseList />} />
      <Route path="/courses/id" element={<CourseDetails />} />
    </Routes>
  );
}
```

## Спільні правила

- Можна використовувати ШІ для пояснення коду, аналізу причин помилок, порівняння рішень і допомоги з реалізацією. Перевіряйте поради запуском застосунку.
- У `README.md` коротко зазначте назву інструмента та для чого його використали; позначте згенеровані фрагменти або файли, якщо вони є. Якщо ШІ не використовували, зазначте це.
- Початковий прогноз/вибір зафіксуйте до запуску або генерації рішення: у нотатці чи на папері. Не замінюйте його після перевірки — додайте, що саме з’ясували.
- Під час індивідуальної зміни біля викладача можна користуватися власним кодом, шпаргалкою та документацією. Нову відповідь агента для цього етапу не генеруйте. Перед виконанням поясніть очікуваний результат.

- Власне покращення та зміна, призначена викладачем, мають бути різними діями.
- Здайте посилання на репозиторій і продемонструйте застосунок. Достатньо коротких нотаток та усного пояснення; великий звіт не потрібен.
