# Набір: N дизайн-напрямів + перемикач

## Як користуватися

1. **Зберіть 3–5 скриншотів-референсів**, по одному на версію. Назвіть їх по порядку: `ref-1.png`, `ref-2.png`, …
2. **Отримайте блоки напрямів.** Заповніть `{{...}}` у `1-directions-prompt.md` і вставте його в Claude разом зі скриншотами. У відповідь прийдуть короткі блоки `v1 — …`, `v2 — …`.
3. **Зберіть версії.** Заповніть `{{...}}` у `2-build-prompt.md` і вставте блоки з кроку 2 на місце `{{PASTE…}}`. Віддайте промпт агенту разом зі скриншотами (у тому ж порядку) і файлом `index.html` з цього набору.
4. **Перегляньте.** Агент створить папки `v1/` … `vN/` і кореневий `index.html` з перемикачем. Відкрийте `index.html`. Якщо рамка порожня, запустіть у цій папці `python3 -m http.server` і відкрийте `localhost:8000`.

## Перемикач (`index.html`)

- Вкладки V1…VN, клавіші `1`–`9` або `←` `→`. Поточна версія зберігається в посиланні (`#v3`).
- Рамки: `390` (телефон), `768` (планшет), `1440` (десктоп), `Full`. Вибір запам'ятовується.
- `Відкрити ↗` відкриває поточну версію окремо: зручно, щоб перевірити на справжньому телефоні.
- На вузькому екрані версія завжди на весь екран.
- Налаштування — тільки блок `CONFIG` угорі файлу: назва продукту, список версій, рамка за замовчуванням.

## Порада

Скриншот передає стиль, блок напряму — лише те, чого на скриншоті немає: як елементи референсу стають вашим контентом, винятки з правил і місце під головне зображення. Якщо блок довший за 90 слів, ви, найімовірніше, описуєте те, що агент і так бачить.
