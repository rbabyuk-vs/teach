# Шпаргалка: як узагалі працює веб

## Головна схема

Коли користувач вводить адресу сайту, відбувається приблизно така послідовність:

```text
користувач вводить URL
        ↓
DNS знаходить IP-адресу
        ↓
браузер надсилає HTTP-запит
        ↓
сервер повертає HTTP-відповідь
        ↓
браузер отримує HTML і створює DOM
        ↓
JavaScript може змінювати сторінку
```

---

## 1. Клієнт і сервер

**Клієнт** — програма, яка надсилає запит. У нашому випадку це браузер.

**Сервер** — програма або комп’ютер, який приймає запит і повертає відповідь.

```text
Браузер  →  запит  →  Сервер
Браузер  ← відповідь ← Сервер
```

Сервер може повернути:

- HTML-сторінку;
- CSS або JavaScript;
- зображення;
- відео;
- JSON-дані;
- файл.

---

## 2. URL

**URL** — адреса ресурсу в інтернеті.

Приклад:

```text
https://example.com/products
```

Основні частини:

| Частина | Приклад | Що означає |
|---|---|---|
| протокол | `https` | спосіб передавання даних |
| домен | `example.com` | ім’я сайту |
| шлях | `/products` | потрібна сторінка або ресурс |

Повний URL може містити більше частин, але поки достатньо розуміти ці три.

---

## 3. Домен та IP-адреса

**Домен** — зрозуміле для людини ім’я сайту:

```text
example.com
```

**IP-адреса** — мережева адреса пристрою або сервера:

```text
93.184.216.34
```

```text
Домен зручний для людини.
IP-адреса потрібна комп’ютерам для з’єднання.
```

`127.0.0.1` — адреса поточного комп’ютера, яку називають **localhost**.

```text
http://localhost:5500
```

Таку адресу часто використовують під час локальної веброзробки.

---

## 4. Порт

**Порт** допомагає визначити конкретну програму або сервіс на комп’ютері.

```text
IP-адреса = адреса будинку
порт      = номер квартири
```

Приклад:

```text
http://localhost:3000
```

Тут:

- `localhost` — адреса комп’ютера;
- `3000` — порт програми.

Поширені порти:

| Порт | Використання |
|---:|---|
| `80` | HTTP |
| `443` | HTTPS |

---

## 5. DNS

**DNS** знаходить IP-адресу за доменним ім’ям.

```text
example.com → DNS → 93.184.216.34
```

DNS можна приблизно порівняти з контактами у телефоні:

```text
ім’я людини → номер телефону
домен сайту → IP-адреса
```

DNS не завантажує сайт. Він лише допомагає браузеру знайти сервер.

---

## 6. HTTP та HTTPS

**HTTP** — протокол, за допомогою якого браузер і сервер обмінюються даними.

**HTTPS** — захищена версія такого обміну. Дані передаються через зашифроване TLS-з’єднання.

| HTTP | HTTPS |
|---|---|
| `http://` | `https://` |
| типовий порт `80` | типовий порт `443` |
| немає захисту TLS | використовується захист TLS |

HTTPS особливо важливий під час передавання:

- паролів;
- платіжних даних;
- персональної інформації.

---

## 7. HTTP-запит і відповідь

HTTP працює за моделлю **«запит — відповідь»**.

```text
клієнт → HTTP-запит → сервер
клієнт ← HTTP-відповідь ← сервер
```

Запит повідомляє серверу:

- який ресурс потрібен;
- яку дію потрібно виконати;
- іноді — які дані надсилає клієнт.

Відповідь повідомляє клієнту:

- чи вдалося виконати запит;
- який результат отримано;
- які дані повертає сервер.

---

## 8. Методи GET і POST

**HTTP-метод** описує бажану дію.

### GET

`GET` зазвичай використовується, щоб отримати дані.

```text
GET /products
```

Приклад: браузер запитує список товарів.

### POST

`POST` зазвичай використовується, щоб надіслати дані або створити новий ресурс.

```text
POST /orders
```

Приклад: користувач надсилає нове замовлення.

| Метод | Типова дія |
|---|---|
| `GET` | отримати дані |
| `POST` | надіслати дані або створити ресурс |

---

## 9. Статус-коди

**Статус-код** показує результат обробки HTTP-запиту.

На початку достатньо знати три коди:

| Код | Значення |
|---:|---|
| `200 OK` | запит виконано успішно |
| `404 Not Found` | ресурс не знайдено |
| `500 Internal Server Error` | на сервері виникла помилка |

`404` не означає, що сервер повністю не працює. Сервер відповів, але не знайшов потрібну сторінку або ресурс.

---

## 10. HTML і DOM

Сервер може повернути браузеру HTML:

```html
<body>
  <h1>Hello!</h1>
  <p>My first page</p>
</body>
```

Браузер читає HTML і створює **DOM — Document Object Model**.

DOM — це представлення сторінки у вигляді дерева об’єктів:

```text
document
└── html
    └── body
        ├── h1
        └── p
```

HTML — код документа.

DOM — об’єктне представлення цього документа, створене браузером.

---

## 11. Навіщо потрібен JavaScript

HTML створює структуру сторінки, CSS відповідає за її вигляд, а JavaScript додає поведінку.

```text
HTML       → структура
CSS        → зовнішній вигляд
JavaScript → поведінка
```

JavaScript може:

- змінити текст;
- прочитати значення поля;
- відреагувати на клік;
- створити новий елемент;
- видалити елемент;
- надіслати запит на сервер.

---

## 12. Маленька демонстрація JavaScript і DOM

У цьому прикладі кнопки додають і видаляють елементи списку.

```html
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>DOM demo</title>
</head>
<body>
  <h1>Мій список</h1>

  <button id="add-button">Додати</button>
  <button id="remove-button">Видалити</button>

  <ul id="list"></ul>

  <script>
    const list = document.querySelector("#list");
    const addButton = document.querySelector("#add-button");
    const removeButton = document.querySelector("#remove-button");

    addButton.addEventListener("click", () => {
      const item = document.createElement("li");
      item.textContent = "Новий елемент";
      list.append(item);
    });

    removeButton.addEventListener("click", () => {
      const lastItem = list.lastElementChild;

      if (lastItem) {
        lastItem.remove();
      }
    });
  </script>
</body>
</html>
```

Поки не потрібно розуміти весь синтаксис. Головна ідея:

| Код | Що робить |
|---|---|
| `querySelector()` | знаходить елемент |
| `addEventListener()` | реагує на подію |
| `createElement()` | створює елемент |
| `textContent` | задає або змінює текст |
| `append()` | додає елемент на сторінку |
| `remove()` | видаляє елемент |

---

## Що потрібно запам’ятати

1. Браузер є клієнтом і надсилає запити серверу.
2. DNS знаходить IP-адресу за доменом.
3. IP-адреса визначає пристрій, а порт — конкретний сервіс.
4. HTTP забезпечує обмін запитами та відповідями.
5. HTTPS використовує захищене з’єднання.
6. `GET` отримує дані, а `POST` надсилає дані.
7. Статус-код показує результат запиту.
8. Браузер створює DOM на основі HTML.
9. JavaScript може змінювати DOM і реагувати на дії користувача.
